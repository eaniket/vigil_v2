# Vigil

Vigil is a video-anomaly detection and emergency-response prototype.

## Repository layout

- `backend/` contains the Flask server, anomaly-detection code, models, demo input/output, templates, and Flask static assets.
- `Website/` contains the standalone dashboard export.
- `data.csv` and `Temporal_Anomaly_Annotation_For_Testing_Videos/` are research datasets not loaded by the active backend.
- `research.md` documents the existing system and its constraints.
- `plan.md` records the backend reorganization plan and validation checklist.

See [`backend/README.md`](backend/README.md) for setup and run commands.
